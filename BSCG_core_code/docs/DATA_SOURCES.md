# Data sources (links only)

- MMCOWS provider repository: https://github.com/neis-lab/mmcows
- MMCOWS dataset paper: https://proceedings.neurips.cc/paper_files/paper/2024/file/6d8f3f71b22f9d2e9320d7bdb73acea7-Paper-Datasets_and_Benchmarks_Track.pdf
- CowBase replication dataset: https://doi.org/10.48804/9FAVEP
- CowBase dataset page: https://rdr.kuleuven.be/dataset.xhtml?persistentId=doi:10.48804/9FAVEP
- CowBase methods paper: https://doi.org/10.1016/j.inpa.2026.01.001

The MMCOWS repository describes the source sensor archive and download mirrors.
CowBase uses the farmB activity, milking, animal and lactation source files.
Access and reuse are governed by each provider's terms. This release does not
redistribute raw records, processed arrays, manufacturer data or author-held
sample manifests. Users supply their own local input adapter and arrays.
